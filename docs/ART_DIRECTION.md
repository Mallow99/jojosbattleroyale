# Art direction — replacement for rejected Star Platinum prototype

## User feedback

On October 24, 2026 the user rejected the first Star Platinum mesh because it
did not look like Roblox, did not fit the project and fell below the required
quality. That model is rejected, not an approved blockout or production baseline.
Do not continue polishing its rounded anatomy, cone hair or face.

## Current working baseline

Use an actual Roblox humanoid/Stand silhouette. Start with the established blocky
body and articulated rig; add character identity through well-shaped hair, armor,
clothing and controlled texture work. Choose the exact target from a visual
comparison of relevant existing Roblox models. The user has been asked whether
YBA-style blocky Roblox or AUT-style detailed Roblox is closer to their intent;
that preference is pending, not approved.

The replacement must have consistent proportions and a recognizable Star Platinum
face, hair, color palette and costume. Avoid the previous stacked-primitive
anatomy, rounded toy-like limbs and mannequin face. Use a clean preview of actual
geometry; an attractive concept image is not evidence of a working game model.

## Selection criteria

- Inspect candidate previews before adapting or rebuilding geometry.
- Prefer models already designed around Roblox body dimensions and joints.
- Inspect acquired packages without running their embedded scripts.
- Record meshes, textures, rig structure and dependencies.
- Verify the complete character silhouette, face, hair and armor before animation.
- Review deformation, render cost and Roblox asset permissions separately from art quality.
- Passing mesh export or rig tests does not establish acceptable visual quality.

The existing rounded model and generator are retained only for history, with
rejection notices. They are excluded from the current recommended asset direction.
